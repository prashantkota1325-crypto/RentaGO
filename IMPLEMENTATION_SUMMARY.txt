CHANGES SUMMARY:
--------------------

1. SEARCH FILTERS ENHANCEMENT:
   - Employees & Individuals masters now have 'entity_name' filter field
   - Filters use AND logic when multiple fields are filled
   - Quick search (q) still works across all fields

2. PACKAGE TYPE OPTIONS:
   - Added 'Per Day' and 'Multiple Days' to package_type datalist
   - Existing options preserved: 4H/40Kms, 8H/80Kms, 12H/120Kms, etc.

3. AUTO-POPULATION & FORM SMART LOGIC:
   - JavaScript auto-runs when guest name input loses focus
   - City/State relationship: clears state field when city is emptied
   - Same logic for Drop city/state
   - Pickup Country field added (default: 'India')
   - Framework ready for future API geocoding integration

4. GPS/ MAP LOOKUP STRUCTURE:
   - Pickup country field in booking form
   - JavaScript framework for: Country -> State -> City -> Location Address
   - NOTE: Actual geocoding requires Google Maps/Mapbox API key integration

5. ACKNOWLEDGEMENT SLA TRACKING:
   - NEW DB COLUMNS on bookings table:
     * request_received_time  (TIMESTAMP - when email/WhatsApp arrived)
     * ack_sent_time          (TIMESTAMP - when acknowledgement sent)
   - SLA target: 15 minutes from request receipt to acknowledgement
   - Booking detail page shows:
     * Request received at [time]
     * Acknowledgement [status: Pending/Sent at X min]
     * BREACHED badge if SLA exceeded
     * "Mark Ack Sent" button (operator action)
   - Auto-stamps ack_sent_time when step1 notification marked "Sent" in outbox

6. MULTI-LOGIN SUPPORT:
   - user_sessions table created in Oracle XE
   - Same user cannot login on multiple devices simultaneously
   - Different users can login simultaneously (as expected)
   - Logging in from a new device automatically invalidates previous session
